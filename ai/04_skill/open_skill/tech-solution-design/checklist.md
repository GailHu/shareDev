# 异常与边界扫描清单

SKILL.md 第 5 步与第 6 步使用。逐类过一遍，命中就在技术方案第 7 章写成一条，每条写清**触发条件 / 系统行为 / 用户可见表现**。不适用的类别写「不适用」并给一句理由，不要直接跳过——跳过和不适用在成稿上看不出区别。

## 一、输入与参数

| 类别 | 扫描问题 |
|------|----------|
| 空与缺省 | 必填字段缺失、空字符串与 null 是否等价、可选字段缺省时取什么值 |
| 长度与范围 | 超长文本如何处理（截断还是报错）、数值越界、负数、零 |
| 格式 | 非法枚举值、时间格式与时区、浮点精度、特殊字符与转义 |
| 分页 | 页码为 0 或负数、页大小超上限、深分页、翻页期间数据变动 |
| 批量 | 批量条数上限、部分成功如何返回、批内重复项 |

## 二、权限与身份

| 类别 | 扫描问题 |
|------|----------|
| 未登录 | 会话过期、令牌失效时的接口行为与前端跳转 |
| 越权 | 横向越权（改 ID 访问他人数据）、纵向越权（普通用户调管理接口） |
| 强制点 | 每条访问限制是否在服务端强制。凡需求写成「不展示 / 看不到」的，一律落到服务端 |
| 数据可见性 | 同一资源对不同角色返回的字段集是否不同，如何实现 |

## 三、并发与时序

| 类别 | 扫描问题 |
|------|----------|
| 重复提交 | 用户连点、前端重试、网关重试——幂等键是什么，重复请求返回什么 |
| 并发修改 | 两人同时改同一条记录，用乐观锁、悲观锁还是唯一索引兜底，冲突时返回什么 |
| 读写竞争 | 写后立即读是否能读到，缓存与从库延迟的上限 |
| 乱序 | 异步消息乱序到达、回调早于主流程落库 |
| 状态竞态 | 状态机在并发下是否可能跳过中间态 |

## 四、外部依赖

| 类别 | 扫描问题 |
|------|----------|
| 不可用 | 依赖服务宕机时本功能降级还是整体失败，降级后的用户表现 |
| 超时 | 每个外部调用的超时值，超时后是否重试、重试几次、总耗时上限 |
| 返回异常 | 返回格式不符预期、字段缺失、返回成功但业务失败 |
| 部分失败 | 调用多个下游时，前几个成功后几个失败，已产生的副作用如何回收 |
| 故障域 | 一个依赖的故障是否会拖垮无关功能（线程池、连接池隔离） |

## 五、数据与存储

| 类别 | 扫描问题 |
|------|----------|
| 不存在 | 查询不存在的 ID、关联对象已被删除、外键悬空 |
| 重复 | 唯一约束冲突时的用户可见行为，是报错还是幂等返回 |
| 删除 | 软删还是硬删，软删数据是否参与唯一约束、统计、关联查询 |
| 迁移期 | 新旧字段并存期间，旧数据缺新字段时读取返回什么 |
| 容量 | 单表数据量增长预期、大字段存储位置、归档策略 |

## 六、失败与恢复

| 类别 | 扫描问题 |
|------|----------|
| 事务边界 | 跨库或跨服务的操作如何保证一致，是否需要补偿任务 |
| 中断 | 进程在执行到一半时被杀，重启后如何检测并恢复未完成的任务 |
| 定时任务 | 上次未执行完下次已触发、执行失败是否重试、重复执行是否安全 |
| 回滚 | 版本回滚后，新版本已写入的新格式数据如何被旧版本正确处理 |

# 非功能核对清单

SKILL.md 第 6 步使用。

## 性能预算

- [ ] 端到端指标已拆到每一跳，各跳之和给上限留出 30% 余量
- [ ] 标出了最慢的一跳，以及它超出预算时的应对
- [ ] 数据库查询逐条核对走的索引，无全表扫描
- [ ] 循环中的数据库或外部调用已消除（N+1）
- [ ] 最长耗时与网关、负载均衡、浏览器的默认超时做过对照

## 可观测性

- [ ] 第 5 步列出的每个失败模式都有对应的日志字段、指标或告警
- [ ] 关键链路有贯穿的请求标识，可串联多个服务的日志
- [ ] 日志字段定义具体到字段名，不是「记录必要信息」
- [ ] 告警配了阈值与触发条件，不是「异常时告警」

## 安全

- [ ] 每条访问限制标明了服务端强制点
- [ ] 敏感字段的脱敏规则、日志落盘范围、对外返回范围都已写明
- [ ] 外部输入在进入存储与渲染前的处理方式已明确
- [ ] 给出了至少一组越权验证用例

## 兼容与迁移

- [ ] 接口变更标注了是否兼容，不兼容的给出并存期与下线时间
- [ ] 数据迁移有脚本、有校验方式、有可重复执行保证
- [ ] 灰度范围与放量节奏已明确
- [ ] 回滚路径写清了数据侧的处理，不只是「回退版本」
