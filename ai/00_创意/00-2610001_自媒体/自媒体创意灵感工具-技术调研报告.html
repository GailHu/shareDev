2. 抖音热榜数据采集方案

📊 可行性评级：高

官方API可用 + 多个成熟开源工具 + 商业API服务完善

2.1 官方API：抖音开放平台

抖音开放平台提供「查询热点视频」能力，包含实时热词、飙升词、以及按热词分组的视频列表。

项目详情
入口developer.open-douyin.com
准入门槛「暂无准入条件，任一应用均可申请使用」
注册要求抖音账号 + 实名认证；个人开发者或企业开发者
返回数据热词、飙升词、视频ID、标题、封面、点赞/评论/分享数、创建时间、热度值
刷新频率热榜约每2小时更新
认证方式OAuth 2.0 授权码流程，获取 Client ID + Secret
优势：免费、官方、稳定、无法律风险。适合获取每日热搜词和对应热门视频。

2.2 商业API：TikHub

TikHub 是面向开发者的付费API服务，提供完整的抖音数据接口：

端点功能价格
fetch_hot_search_list热搜榜单$0.001/次 (3万次/天后降至$0.0005)
fetch_one_video单视频详情(含标签、音乐)
fetch_video_statistics互动数据(播放/点赞/评论/分享)
fetch_video_comments评论及回复
Billboard 系列热门话题/音乐/账号榜

月费 $5-$55 不等（按RPS档位），适合需要结构化JSON、稳定SLA的场景。

2.4 反爬机制与应对

抖音Web端有严格反爬：X-Bogus、a_bogus 签名参数 + 浏览器指纹 + 滑块验证。 自建爬虫需持续跟进签名算法更新，维护成本高。建议优先使用官方API或TikHub，避免直接爬取。

3. B站热榜数据采集方案

📺 可行性评级：高

Web API 公开可用，数据字段丰富，但2026年1月律师函事件需注意法律风险

3.1 核心API端点

B站虽无正式"开放数据API"，但其Web客户端使用的 api.bilibili.com 接口被社区广泛验证：

端点功能参数
GET /x/web-interface/ranking/v2 分区排行榜 rid=0(全站)/1(动画)/4(游戏)/36(知识)...
type=all/origin/rookie
GET /x/web-interface/popular 综合热门 ps=20, pn=页码
GET /x/web-interface/search/square 热搜词 limit=数量
GET /x/web-interface/view 视频详情 bvid=BV号
GET /x/tag/archive/tags 视频标签 bvid=BV号

3.2 返回数据字段

每条视频包含完整元数据：

字段说明字段说明

desc简介stat.like点赞
owner.nameUP主stat.coin投币
pubdate发布时间stat.favorite收藏
duration时长(秒)stat.danmaku弹幕数
tname分区stat.reply评论数

3.3 WBI 签名机制（2023年后必须）

大部分接口现在需要 WBI 签名，否则返回 -799 错误。算法流程：

1. GET /x/web-interface/nav → 提取 img_key + sub_key
2. 拼接后按固定置换表重排，取前32字符 → mixin_key
3. 请求参数追加 wts=当前时间戳
4. 参数按key排序 → URL编码 → MD5(编码结果 + mixin_key) → w_rid
5. 最终请求携带 w_rid + wts
注：密钥每日轮换，需定时刷新

3.4 重要风险事件

2026年1月：B站向 bilibili-API-collect 项目（GitHub 20K+ stars）发送律师函，要求彻底删除所有代码及git历史。bilibili-api Python库随后归档停止维护。

影响：API本身仍可用（驱动官方客户端），但公开文档/工具面临法律风险。Gitee镜像仍存在。

建议：个人研究使用风险较低；商业产品建议走火烧云/飞瓜等授权数据服务。

4. 视频号数据采集可行性评估

💬 可行性评级：极低

微信生态高度封闭，无官方热榜API，爬虫已被大规模封禁

4.1 为什么视频号几乎不可行

限制维度具体情况
官方API仅有「视频号助手API」，面向自有账号的电商/直播运营，无任何热榜/发现类接口
Web端channels.weixin.qq.com 仅为创作者管理后台，无公开浏览/搜索页面
执法力度已封禁 1000+ 个利用爬虫抓取视频号数据的微信账号
技术壁垒无公开搜索端点、分享链接带token过期、小程序数据加密
法律先例有程序员因爬取13万条视频获刑2年的刑事判例

4.2 替代方案（推荐）

既然无法直接获取视频号热榜，可以用以下微信生态代理信号间接捕捉趋势：
替代信号获取方式可行性
公众号热文榜新榜API / 天行数据API (tianapi.com/apiview/197)高
微信指数小程序手动查看 / 逆向(极不稳定)中低
搜一搜热词无API，需手动观察低
新视数据/友望数据付费SaaS，提供估算排行中
务实建议：将视频号定位为"辅助参考"而非"主力数据源"。核心热榜数据从抖音+B站获取（覆盖短视频+中长视频），微信生态用公众号热文做趋势补充。如果预算允许，订阅新视数据(¥5000+/年)获取视频号估算排行。

9. 合规与风险提示

重要：数据采集涉及多部法律，务必在合法合规框架内操作。
法律相关条款风险点
《数据安全法》数据处理需合法正当大规模爬取可能触发
《个人信息保护法》用户画像/评论属个人信息采集用户数据需合规
《反不正当竞争法》不得非法获取竞争对手数据商业化使用需授权
《刑法》第285条非法侵入计算机信息系统绕过技术保护措施可追刑责

各平台风险等级

平台使用官方API使用商业服务自建爬虫
抖音 安全 安全 高风险 (a_bogus绕属规避技术措施)
B站 灰色 (无正式开放) 安全 中风险 (律师函先例)
视频号 无此选项 安全 极高风险 (刑事判例)
合规建议：
1. 优先使用官方API（抖音开放平台）和授权商业服务
2. B站数据仅用于个人研究，控制频率(1-2次/秒)，不公开分发API文档
3. 视频号数据通过正规第三方平台(新视/友望)获取
4. 不采集用户个人信息（评论、头像、粉丝列表等）
5. 仅采集公开可见的热榜/排行数据，不触碰非公开数据
